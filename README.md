# beamic pro

通过 Ophir BeamMic 连接相机的中文光学实验助手，当前版本 **0.5.2**。

## Windows 下载与运行

从 [Releases](https://github.com/liweihan389/beam_pro/releases) 下载：

- `beamic-pro-0.5.2-setup.exe`：安装到当前用户目录，并创建开始菜单入口。
- `beamic-pro-0.5.2-windows-portable.zip`：免安装版，解压后运行 `beamic-pro.exe`。
- `SHA256SUMS.txt`：下载文件的SHA256校验值。

0.5.2 重构取帧：在新帧回调内取得同一帧对象的字段并复制数值图像，再由独立线程传输；不再把可能保持不变的 `UniqueKey` 当作去重或快照一致性的证明。只保留最新待处理快照，曝光、暂停及接口预检会建立新的采集边界，丢弃边界之前的待处理数据。默认配置仍仅开放数值预览；回调一致性、实时来源、线程约定、曝光与线性量程需按安装的 SDK 验证后才能正式测量。

连接时选择新版随附的 `device-profile.example.json`，曝光预检报告可先取消。默认配置保留未知的曝光、Gamma 和饱和量程；不会从位深推测量程或把当前曝光设置当作逐帧曝光。旧版配置文件不会自动迁移。点击“状态与预检”的导出按钮会短暂停止原版采集以读取接口，再恢复先前的运行状态；报告包含字段类型、数组结构、回调／快照计数和处理耗时，不包含像素图像。软件快照序号与预览帧率不代表硬件帧计数或已验证的有效新帧率。

使用 Windows x64；.NET Framework 4.8 是桥接程序的运行要求。真实相机连接需要已授权的原版 BeamMic 和相机驱动。第一次建立独立的共享插件环境需要联网安装依赖。

可以从开始菜单选择“模拟光路”，或运行 `beamic-pro.exe --demo`，在没有相机时体验功能。模拟结果不能代替真实设备或光学实验验收。

## 功能

- 实时数值图像、几何中心与相对强度边界圆／椭圆定位，支持主光斑选区。
- 自动曝光“曝光稳定”默认开启；关闭后保持当前曝光，仍排除旧曝光及无效帧。
- 自动定圈默认开启，可固定参考圈、标记当前中心并连接两个中心。
- 预览按窗口大小缩图，定位和测量使用原始数值图像；上次定位圈注明距收帧时间，超过2秒隐藏，固定参考圈另行保留。
- 可暂停采集／当前记录；正式记录时原版 BeamMic 仅用于查看，修改相机、历史帧或采集设置前先暂停。
- 固定DM、调节蓝光两面反射镜的双镜合束引导。
- 使用独立D4σ宽度的束腰测量：三点建模、两个新点验证，允许补测。
- 单镜等高默认开启，可选coupler手动调焦及区间准直验证；组合模式先准直、再等高。
- Python插件安装、启停和独立进程运行，包含三个实验引导插件及基础分析示例。

目标为20个新的有效帧/秒，支持设置与自动降档；每次正式位置记录默认20个有效新帧。真实设备吞吐和端到端延迟尚需实测。

公开版本仅包含源码及程序，不包含本地操作教程截图、图文测试报告、原始数据集或实验记录。图像与测量会话默认只在内存中；主动开启诊断后可保存一小批原始数值帧及关联状态，尚不替代完整的实验会话记录。

## 实机诊断保存

1. 连接相机，确认图像正在刷新，在“状态与预检”手动勾选本地诊断保存。
2. 默认保存5张，可选1～20张。点击保存并选择本机目录，程序后台写入独立的时间戳文件夹；慢磁盘会漏采并计数，不积压采集队列。
3. 文件夹内 `manifest.json` 记录完成／部分完成状态、漏采、帧类型及相关事件；`frame-*.npz` 包含原始精度的二维数值数组和 JSON 元数据。可用 NumPy 的 `np.load(path, allow_pickle=False)` 读取 `pixels` 与 `metadata_json`。
4. 未知的逐帧曝光和量程仍保存为未知；另列的曝光设置值仅是最近一次控制查询值。勾选关闭、切换来源／坐标、暂停或调整曝光会停止本轮保存，超时保留已完成部分。

诊断默认关闭，文件只保存到所选本机目录，没有自动发送或上传功能。需要分析时由用户决定是否分享该文件夹和单独导出的状态报告。

## 源码运行

需要CPython3.12 x64：

```sh
python -m venv .venv
# Windows使用 .venv\Scripts\python.exe；macOS/Linux使用 .venv/bin/python。
python -m pip install -r requirements-core.lock -e sdk -e ".[dev]"
python -m beamic_pro.app --demo
```

上述安装和启动应使用虚拟环境中的Python，或先激活虚拟环境。

## 测试、打包与插件

```sh
python -m pytest -q
python scripts/package_plugins.py
```

在Windows上运行 `scripts/build_windows.ps1`，构建程序、桥接、插件、便携ZIP及Inno Setup安装包。需要.NET SDK与Inno Setup 6；`-SkipInstaller`仅构建便携版。默认排除本地图文资料。

GitHub Actions的Release流程在Windows上测试、构建并发布安装包，创建版本标签和校验文件；真实BeamMic／SP932U接口、光高精度与实验表现仍需设备预检和独立参考核查。

插件实现位于 `plugins/alignment`、`plugins/waist`、`plugins/level` 和 `plugins/basic_analysis`；SDK位于 `sdk`，当前版本2.1.0、协议版本2。安装ZIP到“插件库”，引导任务一次运行一个，分析插件可并行读取最新数值帧。
