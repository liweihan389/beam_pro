# 单镜等高与准直插件 0.1.0

要求 beamic pro 0.5.0、SDK 2.1.0。插件包为 `dist/plugins/level.zip`，在“插件库”导入后打开“等高／准直”。默认仅光高，可选择仅准直或两项同时。所有测量保存在内存，退出或重置后不保留。

## 安装与实验前提

单镜后到CCD之间是自由传播或平面反射，不放入透镜等有光焦度元件。近、远CCD使用同一固定高度导轨／支架，竖轴对应平台法线，方向、倍率、有效像元和采集坐标不变。单镜调整时有效反射点近似固定。系统无法从图像判断CCD是否整体升高或倾斜；这一误差必须由固定基准和预算控制。

距离从单镜有效反射点沿传播路径量到感光面。SP932U原始像元3.45 μm，感光面相对本体前端面内缩4.5±0.11 mm；滤片外缘不是此参考面。合并、缩放或成像系统须另核对有效像元及倍率。模拟器使用20 μm合成像元，不能照抄到真实相机。

准直要求coupler具有独立轴向调焦功能；角度支架本身不能改变光束会聚或发散。用户手动小步调焦，软件只提供尺寸反馈和重新测量流程，不推测旋钮方向或圈数。

## 等高计算和复测

默认距离L₁=100 mm、L₂=900 mm，要求0≤L₁<L₂且间距大于两倍位置公差。近、远所选几何中心纵坐标为y₁、y₂，共用图像坐标。远处目标为：

```
y_target = y₂ − L₂ / (L₂ − L₁) × (y₂ − y₁)
```

调单镜时近处光斑也会移动；因此目标通常不是原先的近处纵坐标。仅显示水平目标线及辅助容差带，横向位置自由。三个连续有效新帧进入目标带后，可确认并记录新的远处20帧；再回近处记录新的20帧。最终验收仅用这两次新记录。

默认绝对高差单侧95%上限≤0.05 mm才通过。这是近远等高，不测量光束的绝对平台高度。目标超出画面时需粗调后重新测量。

## 准直流程及判定

1. 近远各20帧粗查，提供尺寸趋势。两端一样大也不能直接判定准直，区间内部可能存在束腰。
2. 用户手动调coupler。实机每次调过都须点“已调coupler”，清空本轮所有宽度、预测、中心和等高目标。模拟调焦控件会自动通知插件。
3. 调焦完成，重新记录近端、远端、中间三个点，默认相对位置0、800、400 mm。冻结此模型，暂不通过。
4. 再记录两个未参与建模的新位置，默认200、600 mm。用户可填写实际位置；任意两点须相距大于两倍位置公差。
5. 两个新点与冻结预测一致后，用全部五点重算区间结果；两方向联合95%变化上限≤5%才通过。失败可补测，原独立验证失败不会被后续重拟合抹去；重新调焦需重新验证。
6. 同时选等高时，准直通过后重新测量近远几何中心，再调单镜。再次调coupler将使两项结果都失效。

宽度为独立强度二阶矩D4σ，在固定CCD X/Y方向计算，不取显示圈半轴。D²(z)作加权二次回归；检查区间两端及内部极值，以`max(D)/min(D)−1`定义直径变化。近平坦曲线不必反推出束腰位置。这里评估指定有限区间的准直程度，不能外推为全传播距离零发散，也不是ISO M²认证。

物理一致性使用两方向均须满足的自由传播下限`A>0`、`(A*C−B²/4)/span² ≥ (4λ_nm/π)²`，D以μm、距离以mm、系数采用归一化位置。误差抽样明显与物理下限冲突时拒绝；曲率无法分辨时标“物理参数未能确定”，保留原抽样做区间评价，不能宣称测得M²。误差产生的负曲率抽样不会被删掉来缩小区间。

## 默认误差预算

| 项目 | 默认值及处理 |
| --- | --- |
| 位置读数 | 每点±10 mm均匀范围；准直相对位置共用近处原点误差 |
| 支架高度重复定位 | 每次±0.010 mm均匀范围，计入等高目标和最终复测 |
| 像元／倍率共同尺度 | ±2%均匀范围，所有位置和两方向共享 |
| 宽度帧内统计 | 每位置20个新有效帧，校正时间相关，保留0.2%独立宽度误差下限 |
| 不确定度传播 | 每次拟合10,000次抽样；两个方向以最大变化作联合上限 |
| 独立预测检查 | 两位置×两方向的创新区间，使用Bonferroni分配总体5%尾概率 |

这些数值是可修改的条件假设，尤其±0.010 mm不是对任意支架的能力保证。未知系统偏差不会因平均20帧自动消失。位置、尺度和高度误差也不会靠增加帧数被除以√20。

饱和、无效量程、未稳定曝光、重复帧、旧曝光、截断、背景不足或积分范围敏感时暂停宽度记录。来源／坐标／ROI／有效像元改变清空会话。曝光由主程序统一管理。

## 检查与教程

- `tests/test_level.py`：数学、拒绝条件、测量状态与清空行为。
- `tests/test_ui_level.py`：真实界面按钮和独立插件进程中的等高、仅准直流程。
- `scripts/check_level_workflow.py`：实际程序窗口逐步截图，包含组合模式与精度不足反例。
- `scripts/check_level_numerics.py`：120组带宽度噪声的合成高斯传播敏感性检查，不代表真实硬件准确度或已证明95%覆盖率。
- 主程序文档 `docs/单镜等高准直操作说明.html` 可离线浏览，验收状态见 `docs/单镜等高准直验收记录.md`。
