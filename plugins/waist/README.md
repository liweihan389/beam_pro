# 束腰测量插件

需要 beamic pro 0.4.0 和 SDK 2.1.0；SDK 协议版本仍为 v2，旧插件兼容。插件仅依赖 SDK 和 NumPy，测量结果在内存中保留，停用或重新开始后释放。

默认流程：三点建模 → 冻结预测 → 两个新位置独立验证 → 五点重算 → 精度判断 → 必要时补测。初始三点不足以形成可靠物理解时，可以增加建模点，之后仍需要两个新的独立验证点。修改建模点会废除原预测及验证；重录首点会改变零点，需要重建所有相对距离。

使用固定相机 X/Y 方向的强度二阶矩直径 D4σ。高斯光束下，D4σ 是 1/e² 直径；对双峰、环形等非高斯光束不使用几何拟合圈半轴。软件检查背景、饱和、截断、信噪比、积分范围敏感性和像素采样。没有通过宽度检查的数据不会录入，也不宣称测得 M²。

默认公差 ±10 mm，解释为每个外壳基准读数的误差范围；相对坐标读数相减时共享首次读数误差。首次感光面本身是相对零点，不再给 l1 重复添加误差。公差按均匀分布；同点20帧的波动考虑正相关，并保留0.2%的局部尺寸标准不确定度下限。共同宽度系统公差默认±2%，按所有点和两方向共用的比例误差传播；这是参考厂家宽度标称准确度设置的保守预算假设，不是像元公差，也不能覆盖未知背景／模型错误。

误差模拟默认2500次，保留两方向都具有正曲率及正最小尺寸的模拟结果；物理解比例低于90%时拒绝锁定。区间取2.5%–97.5%分位数，属于输入误差模型下的近似传播区间。三点残差不被用于估计噪声；最终全点一致性使用包含距离误差和共享零点的协方差。验证针对冻结模型，合并新位置和新宽度误差；两个验证位置×两个方向使用保守的名义95%联合检验。区间不是普遍的准确度保证。

默认完成门槛：两个方向直径95%区间相对半宽≤5%，位置区间半宽≤5 mm，同时验证一致、全点传播一致且预测束腰直径不少于10个有效像素。宽度区间误差门槛和位置门槛分别可调。

SP932U 原始像元为3.45 μm，直测倍率默认1；合并或缩放须填有效像元，成像须核对倍率。帧报告像元与输入不一致时拒绝记录。相对位置不需要感光面偏移；可选绝对位置输入“参考点到首次本体前端平面”的距离，加上4.5 mm感光面内缩，按±0.11 mm范围传播偏移公差。外部参考点必须固定，前端面不包含滤片最前缘。
